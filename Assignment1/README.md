## Assignment Overview

This repository contains my TypeScript assignment solutions,demonstrating my understanding of TypeScript fundamentals,functions,type safety, generics,interfaces,classes,inheritance and asynchronous programming.

## Topics Covered:
Optional Parameters: Implemented a multiplication function with an optional multiplier and a default value.

Union Types and Type Narrowing: Processed string,number and boolean inputs using typeof checks.

Tuple and Readonly: Used a readonly tuple to store and format geographic coordinates.

Generics: Created a reusable function to concatenate multiple arrays of the same type.

Interfaces and Array Filtering: Defined a Course interface and filtered published courses based on student enrollment.

Generics and keyof: Implemented a generic function to extract specific property values from objects.

Classes and Inheritance: Demonstrated constructor usage,access modifiers and inheritance using Employee and Manager classes.

Promises and Async Programming: Implemented an asynchronous age validation function using Promise,accept,reject and setTimeout.
